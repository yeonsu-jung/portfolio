Entangling 15 rods

Fifteen rods start parallel with their centres on a ring. A minimiser then raises the total linking number between them while a stiff repulsion pushes apart any pair that gets closer than one rod diameter.

What the run does

  • Start. Rod centres sit on a ring of radius 0.6 and every rod points along x, so rods at mirrored positions lie on the same line and overlap. The first frame is therefore not penetration-free, and its total linking is exactly zero.
  • Energy. The minimiser lowers −w·Σ|Lkij| + A·Σ(D − dij)², where the second sum only counts pairs with centreline distance d below the diameter D. Here w = 10, the default, and A = 5000.
  • Motion. FIRE moves each rod's centre and its two orientation angles. The frames shown are spaced evenly in log iteration.
  • Result. The starting overlaps clear in roughly the first 60 iterations, as rods on the same line slide off each other. Σ|Lk| climbs from 0 to 31.4 across the 105 pairs, with 25.9 reached by iteration 300. Between iterations 100 and 400 the closest pair dips as low as 0.93 D. From iteration 400 on it holds between 0.96 and 0.98 D. The repulsion is a penalty, not a hard constraint, so the rods end up pressed about 2–4% into each other.

How this page was made

This is a fresh run of entanglement_optimization, built from the current source, with the settings of movie_N15_L2_Rad0.1.mp4. It is not the December 2025 trajectory, which no longer exists. The rods start exactly parallel. The solver offsets each centre by up to 0.0001 in z, which is enough to break the symmetry.

./entanglement_optimization --num-rods 15 \
    --rod-length 2 --rod-radius 0.1 \
    --max-iter 3000 --force-tol 0 --no-relaxation \
    --save-interval 2 --log-interval 2

Linking numbers come from the run's log. Distances and touching pairs (within 2% of one diameter) are recomputed from the saved rod positions. The same calculation on the solver's final configuration reproduces the minimum distance it reports.

The thin-rod case is on a second page: 100 rods at aspect ratio 200.
